# Story scope — US-15 Version control (git)

**Story:** US-15  
**Title:** Version control for config and memory (git)

---

## Formulation

As an operator, I want the assistant to use a git repository in its working directory to track designated data changed by PA itself, so that I can review history and recover safely when needed.

**Status:** Deferred (post-MVP, out of EP-001 implementation scope).

**Reason:** The story requires additional safe restart/rollback orchestration, security hardening for self-modifying behavior, and dedicated reliability tests that are intentionally postponed after MVP.
