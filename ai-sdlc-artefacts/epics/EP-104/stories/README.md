# stories — Story-level artefacts

Story-level artefacts (e.g. acceptance criteria) live here. One folder per user story ID (e.g. US-01, US-02). Each folder may contain `acceptance-criteria.md` with the AC for that story; the source of truth for AC is the per-story file.

Convention: [ai-sdlc/specification/pipeline.spec.md](../../../ai-sdlc/specification/pipeline.spec.md) (Artefact levels, Section 3 Story-level).
